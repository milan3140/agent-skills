# Presentation Builder

**核心心法:簡報不是把資料排版,是把「你要對方做的決定」放到他面前。**

---

## 一、先回答三個問題(沒答完不要開始做頁面)

1. **這份簡報要對方做什麼決定?**(批准 / 選 A 或 B / 給資源 / 只是知會)
2. **對方腦中現在的版本是什麼?**(他相信什麼、上次聽到什麼、他會反駁哪一點)
3. **如果只能留一頁,那頁寫什麼?**

答不出 1 → 這份簡報不該做,先去問。

---

## 二、結構(顧問體)

```
P1  執行摘要        ← 最常缺、卻最重要的一頁
P2  現況與問題      ← 三個數字 + 一句解讀
P3~ 分章論證        ← 每章開頭一句結論,後面才是證據
Pn  抉擇與資源要求  ← A/B 兩欄表 + 你的建議 + 你要什麼
附錄 方法與資料來源
```

### P1 執行摘要必含四塊(缺一不可)

| 塊 | 內容 | 常見錯誤 |
|---|---|---|
| **一句 insight** | 串起「診斷 → 手段」的那句話 | 寫成工作摘要(「本季完成 X、Y、Z」) |
| **現況三數字** | 三個帶母體與時間窗的關鍵量 | 只有百分比、看不出分母 |
| **A/B 抉擇表** | 兩欄並列 + **你表態建議哪個** | 只列選項不表態(責任外包) |
| **一個資源要求** | 具體到人/時間/預算 | 寫成「需要更多支援」 |

---

## 三、每一頁的規則

1. **標題是主張句,不是名詞**
   - ✗「使用者留存分析」 ✓「留存斷點在第 2 週,不是第 1 週」
2. **一頁一個論點**,論點寫在最上面,證據在下面
3. **每個數字都要能自己說出**:誰(母體)、佔誰幾成、什麼期間、名稱對回哪個欄位
   - 內部速記(欄位名、代號、工單號)在讀者眼裡是零資訊,一律翻成白話
4. **圖表徽章上的百分比**,先寫出「它回答讀者哪個問句」;設計成正反相加 ≈100% 好自我校驗
5. **分類欄位要附判定式**(這個分類怎麼判的),以及已知的污染來源
6. **代號定義貼在圖旁邊**,不要放附錄——讀者連問兩次代號 = 定義離圖太遠

---

## 四、圖表選擇

| 想表達 | 用什麼 | 不要用 |
|---|---|---|
| 組成/佔比 | 堆疊長條 + 直接標數字 | 圓餅(超過 3 類就讀不出來) |
| 隨時間變化 | 折線;強調端點 | 3D、雙 Y 軸 |
| 比較大小 | 橫向長條,由大到小排 | 雷達圖 |
| 狀態轉移 | 轉移矩陣 + 對角線標註方向 | 桑基圖(除非真的要看流) |
| 單一關鍵數字 | 大字 + 一句解讀 | 儀表板 gauge |

**永遠不要雙 Y 軸**——兩個量級不同的量請拆兩張圖或轉成指數化。

## 五、產出與交付

### 5.1 HTML → PDF(推薦路徑)

用 HTML 寫版面(可控、可版控、可重製),再用**系統瀏覽器的 headless 列印**轉 PDF:

```bash
# Windows(Edge/Chrome CLI;不要用 Ctrl+P,也不需要 Playwright)
"<瀏覽器路徑>" --headless --disable-gpu --print-to-pdf="out.pdf" --no-pdf-header-footer "file:///<絕對路徑>/deck.html"
```

### 5.2 產出後自檢(**必跑**)

1. **抽 PDF 全文**(PyMuPDF 等)掃殘留的內部術語、待補、Lorem
2. **逐頁看圖**(轉圖檢查),確認:
   - SVG viewBox 沒有裁掉內容
   - 數字與徽章沒有同行壓字
   - 連線/箭頭沒有疊到文字
3. **每頁問一次**「這頁的主張句是什麼」——答不出來就刪掉或合併

### 5.3 內部術語白話化(整句換,不是查字典)

- 長詞先於短詞替換,避免「未接後端介面時」這種壞句
- 帶動詞的整句一起換
- 換完收掉多餘的中中空格
- **標題也要過**一次
- 抽全文再掃一次殘留

## 六、常見退件原因

| 退件 | 根因 | 修法 |
|---|---|---|
| 「看不懂重點」 | 沒有執行摘要 / 標題是名詞 | 補 P1、標題改主張句 |
| 「這數字哪來的」 | 沒有母體與時間窗 | 每格補「誰/幾成/期間/口徑」 |
| 「所以要我做什麼」 | 沒有抉擇表與資源要求 | 補 A/B 表並表態 |
| 「這跟上次講的不一樣」 | 沒對齊對方腦中版本 | 開頭補「與上次的差異」段 |
| 「太細了」 | 事件級細節給到主管層 | 細節移附錄,正文只留決策相關 |
| 「圖看不懂」 | 圖表型態選錯 / 代號離圖太遠 | 照 §4 換型態、定義貼圖旁 |
